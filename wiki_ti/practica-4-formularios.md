# Práctica 4: Formularios

**Resumen**: Enunciado y ejercicios de la Práctica 4 de Tecnología de la Información. Construcción de formularios para las tablas de la base de datos de albaranes, incluyendo combos y subformularios.

**Asignatura**: Tecnología de la Información

**Fuentes**: Raw/Tecnologia de la informacion/Tema 4 - Formularios/Práctica 4. Formularios.md

**Última actualización**: 2026-05-19

---

Los formularios permiten a los usuarios introducir, modificar, eliminar y consultar la información de las tablas de forma cómoda (fuente: Práctica 4. Formularios.md).

## Ejercicio 1: Formulario para Compañías

Crear un formulario para la tabla Compañías con los campos Nombre y Dirección sede (fuente: Práctica 4. Formularios.md).

## Ejercicio 2: Formulario para Camiones

Crear un formulario para la tabla Camiones y mejorar su diseño: modificar la posición y el tamaño de los controles, sus colores y otras propiedades (fuente: Práctica 4. Formularios.md).

## Ejercicio 3: Formulario para Gasolineras

Crear un formulario para la tabla Gasolineras con los campos IDGasolinera, Nombre, Dirección, Compañía (mediante combo desplegable) y Tarifa (fuente: Práctica 4. Formularios.md).

Véase [[formularios-access]] para el proceso de creación de un combo.

## Ejercicio 4: Formulario para Albaranes

Crear un formulario para la tabla Albaranes donde (fuente: Práctica 4. Formularios.md):

- La gasolinera se seleccione desde una lista.
- El camión se seleccione desde un combo desplegable.

## Ejercicio 5: Formulario de camión con subformulario de albaranes

Crear un formulario donde la cabecera muestre los datos del camión y el subformulario muestre los albaranes de ese camión. No debe permitirse modificar la información del camión desde este formulario (fuente: Práctica 4. Formularios.md).

Véase [[subformularios-access]] para el proceso de creación y vinculación.

## Ejercicio 6: Mejora del subformulario

Modificar el formulario del ejercicio 5 para que en el subformulario (fuente: Práctica 4. Formularios.md):

- En lugar del código de gasolinera aparezca el nombre de la gasolinera.
- La gasolinera se pueda seleccionar desde un combo desplegable.
